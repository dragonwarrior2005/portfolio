# Taysir Rahman — Portfolio

Personal portfolio site: Computer Science (Co-op) student at McMaster University.

A scroll-driven story focused on software engineering and data science, in chapters (Focus, Software, Data, Experience), built with plain HTML, CSS and JavaScript, no build step:

- `index.html`: page structure and content
- `style.css`: styles, responsive layout, light and dark mode
- `src.js`: loader, smooth scroll, 3D chip (Three.js), mini brick-breaker demo, data animation, marquee, custom cursor and menu

Libraries load from CDNs: [Three.js r128](https://threejs.org/) and [Lenis](https://github.com/darkroomengineering/lenis). If WebGL is unavailable, a flat SVG chip is shown instead. Animations are reduced when the visitor's system asks for reduced motion.
